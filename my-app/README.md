# 节日祝福自动回复助手

一个智能的节日祝福自动回复应用，可以根据关键词自动识别节日并发送相应的祝福消息。

## 功能特点

### 🎯 核心功能
- **智能识别**：自动识别节日关键词（春节、中秋、国庆、圣诞、生日等）
- **自动回复**：根据识别的节日自动发送相应的祝福消息
- **模板管理**：内置丰富的节日祝福模板，支持自定义添加
- **实时预览**：实时预览祝福消息效果

### 📊 数据统计
- 今日回复数量统计
- 本周回复数量统计  
- 模板使用次数统计
- 实时活动记录

### ⚙️ 高级设置
- 回复延迟时间设置
- 每日发送限制
- 随机模板选择
- 关键词匹配规则
- 定时发送功能

### 🎨 界面特色
- 现代化响应式设计
- 优雅的动画效果
- 直观的用户界面
- 移动端适配

## 使用方法

### 1. 启动应用
```bash
# 在项目目录中
open index.html
```

### 2. 配置设置
- 点击右上角设置按钮
- 调整回复延迟、发送限制等参数
- 保存设置

### 3. 管理模板
- 浏览内置的节日祝福模板
- 点击"添加模板"创建自定义祝福
- 编辑或删除现有模板

### 4. 测试功能
- 点击"测试回复"按钮体验自动回复
- 查看实时预览效果
- 监控活动记录
