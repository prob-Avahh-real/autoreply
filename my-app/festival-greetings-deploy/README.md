# 节日祝福自动回复助手 - PWA版本

## 📱 安装到手机

### 方法一：直接访问安装
1. 用手机浏览器访问应用地址
2. 等待页面加载完成
3. 点击浏览器菜单中的"添加到主屏幕"或"安装应用"
4. 确认安装，应用图标将出现在手机桌面

### 方法二：扫码安装
1. 用其他设备访问应用地址
2. 将二维码显示在屏幕上
3. 用手机扫描二维码
4. 按照方法一的步骤安装

## 🌟 功能特点

- **84个精选模板**：涵盖传统节日、现代节日、西方节日
- **智能分类**：按节日和体裁分类浏览
- **自动提醒**：节日自动推送通知
- **联系人管理**：管理需要祝福的联系人
- **离线使用**：支持离线缓存，无网络也能使用
- **响应式设计**：完美适配手机、平板、桌面

## 📋 系统要求

- **iOS**：iOS 11.4+ (Safari浏览器)
- **Android**：Android 6.0+ (Chrome浏览器推荐)
- **其他**：支持PWA的现代浏览器

## 🔧 技术特性

- **PWA技术**：渐进式Web应用
- **Service Worker**：离线缓存和后台同步
- **响应式设计**：适配所有设备尺寸
- **本地存储**：数据保存在设备本地
- **推送通知**：节日提醒功能
