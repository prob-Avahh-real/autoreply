# 节日祝福自动回复助手 (AutoReply)

面向春节、元旦、中秋、国庆、圣诞、生日等节庆场景的智能祝福模板管理与自动回复响应式 Web / PWA 应用（位于 `my-app/`）。支持按节日分类检索祝福语、个性化推荐排序、节日日历提醒、联系人名单管理及离线 Service Worker 缓存。

## 核心功能

- **多节日模板库**：内置春节、元旦、中秋、国庆、圣诞、生日与自定义分类模板，支持预览、编辑、热度统计与一键分享。
- **关键词识别与模拟回复**：识别节庆问候关键词并自动匹配对应类别祝福语，实时更新今日/本周回复统计与活动时间线。
- **联系人与定时关怀**：内置近期节日日历视图与联系人手机号格式校验（中国大陆 11 位手机号校验）及开关控制。
- **PWA 离线支持**：配备 `manifest.json` 与 `sw.js` Service Worker，可添加到手机或平板主屏幕离线访问。

## 目录结构

```text
autoreply/
├── my-app/
│   ├── index.html      # 响应式主界面（手机 / 平板自适应）
│   ├── app.js          # 模板筛选、推荐引擎、联系人管理与模拟自动回复逻辑
│   ├── server.js       # 零依赖本地静态与 PWA 调试服务器（默认端口 3000）
│   ├── manifest.json   # PWA 应用清单
│   └── sw.js           # Service Worker 离线缓存脚本
├── tests/
│   └── smoke.test.mjs  # 模板筛选、分类映射、手机号校验与静态资源自动化测试
└── package.json
```

## 快速开始

```bash
# 运行自动化测试
npm test

# 启动本地 PWA 预览服务器（http://localhost:3000）
npm start
```
